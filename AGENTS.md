# Project: Shaurya Gupta's Portfolio website
## What this product does
This is an interactive portfolio website for Shaurya Gupta, a student who is a full stack developer currently working and learning the feild of AI. Knows about ML concepts. A more to be specific he is a backend developer with a intrest in AI and Web3. He has a good understanding of machine learning concepts. 
## Stack (do not change without asking)
- Frontend: React.js + Shadcn + Tailwind CSS
- Backend: Node express
- Database: MongoDB + Firebase
- Auth : OAuth 2.0 + JWT
- Hosting: Vercel + Railway 
## Rules
- Never commit secrets. All secrets go in environment variables, documented in .env.example.
- Every new API endpoint needs: input validation, auth check, authorization check, tests.
- Every database change goes through a migration file. Never edit the DB by hand.
- Run lint, typecheck and tests before saying a task is done.
- Ask before adding a new dependency.
- Prefer small, reviewable changes. One feature per branch.
## Commands
- Dev: [npm run dev]
- Test: [npm test]
- Lint/typecheck: [npm run lint && npm run typecheck]
- Migrate: [npx prisma migrate dev]
